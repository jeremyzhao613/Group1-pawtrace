# PawTrace 10.0.0 Final 更新总文档 / Final Comprehensive Update Document

## 中文完整版

### 1. 版本定位

- **版本号**：10.0.0 Final
- **版本类型**：硬件遥测链路、前端演示体验、运营监控、Cloudflare 部署、NFC 宠物卡、聊天贴纸和 3001 Glass Dashboard 的最终综合版本。
- **当前分支**：`main`
- **当前基准提交**：`4b53bae`
- **文档范围**：基于当前工作区相对 `HEAD` 的全部本地改动整理，包含已暂存、未暂存和新增未跟踪文件。
- **核心方向**：PawTrace 从 9.0.0 的 BLE 遥测桥接方案，正式切换到 **Wi-Fi-only 设备遥测**。BLE 现在只负责一次性 Wi-Fi 配网，真实 GPS、健康、活动、电量和上传状态全部通过 Wi-Fi HTTP 上传到后端。

### 2. 一句话总结

10.0.0 Final 将 PawTrace 打包成一个更接近真实展示和交付的端到端版本：M5StickC Plus 通过 Wi-Fi 上传遥测，BLE 只做 Wi-Fi 配网；主 App 可读取 M5 同网段 LAN API、显示健康和地图状态、生成 NFC 宠物卡、发送 36 张宠物贴纸；后端支持 LAN/hotspot 演示免 token、过滤 BLE 遥测、扩展监控数据；Glass Dashboard 和监控大屏改为 Wi-Fi-only 数据口径；项目新增 Cloudflare Pages 部署配置和运行时 API URL 注入。

### 3. 与 9.0.0 的关键差异

- 9.0.0 文档记录的是 BLE telemetry bridge：浏览器订阅 BLE notify 后再 POST 到后端。
- 10.0.0 Final 取消 BLE 作为数据上传路径：`POST /api/device/telemetry` 会拒绝 BLE telemetry payload。
- BLE 的新职责是 provisioning：通过 GATT 写入 Wi-Fi SSID、password、backend host/upload URL 和 device token。
- M5StickC Plus 的主 firmware 改为可持久化 Wi-Fi 配置、自动重连、队列缓存、同网段 HTTP API 和 Wi-Fi HTTP 上传。
- 前端 Health 页从 “Bluetooth Bridge” 改成两个清晰模块：`BLE WiFi Setup` 和 `WiFi Telemetry`。
- Glass Dashboard 删除 BLE demo 包，所有地图和健康展示都以 Wi-Fi HTTP telemetry 为准。

### 4. 系统架构更新

#### 4.1 新硬件数据链路

```text
GPS v1.1 + Heart Rate HAT + IMU
  -> M5StickC Plus Wi-Fi station
  -> same hotspot / LAN
  -> HTTP POST /api/device/telemetry
  -> Express backend
  -> Prisma + PostgreSQL
  -> latest cache + history query
  -> Main App / Map / Health / Pet Cards / Glass Dashboard / Monitor Dashboard
```

#### 4.2 BLE 新职责

```text
Main App Health -> BLE WiFi Setup
  -> Web Bluetooth connects PawTrace-001
  -> write wifi_config JSON to BLE config characteristic
  -> M5 saves SSID/password/upload URL/token
  -> M5 connects Wi-Fi
  -> telemetry leaves device through Wi-Fi only
```

#### 4.3 M5 同网段 LAN API

Wi-Fi firmware 在 M5 连接热点或局域网后提供 `http://<m5-ip>:8080`：

- `GET /`：返回设备能力和 endpoint 列表。
- `GET /status`：返回当前 live telemetry JSON。
- `GET /telemetry`：`/status` 的别名。
- `POST /message`：向 M5 屏幕和状态写入一条消息。
- `POST /upload`：排队一条 telemetry sample 并立即尝试上传到 PawTrace 后端。
- 所有 LAN API 返回 CORS 头，便于同热点手机或电脑浏览器直接访问。

- `DEVICE_INGEST_ALLOW_LAN` 支持 `1/true/yes/on`。
- 当该变量启用时，来自私有网段的 M5 客户端可在本地 hotspot/LAN demo 中免 token 上传。

#### 5.3 Wi-Fi-only telemetry 规则

- `POST /api/device/telemetry` 现在会拒绝 BLE telemetry payload。
- 默认 telemetry source 从 `m5stack-http` 调整为 `m5stack-wifi-http`。
- 后端继续接受标准 JSON telemetry，但不会把 BLE 包写入健康表、位置表或 latest cache。
- latest cache、history query 和 location points 都会过滤 BLE 数据，只保留 Wi-Fi telemetry。
- `GET /api/device/telemetry/latest` 的查询上限使用统一 bounded positive integer 逻辑。
- `GET /api/device/telemetry/history` 默认上限提升到 `120`，最大 `500`，并支持 `from/since` 和 `to/until` 时间范围。
- `/api/location/points` 会读取更多原始点后过滤 BLE source，避免历史 BLE 位置影响地图。

### 10. M5Stack BLE firmware 更新

文件：`hardware/m5stack/pawtrace_ble_telemetry.ino`

#### 10.1 新 BLE contract

- Firmware version：`10.0.0-ble-wifi-provision`
- Device name：`PawTrace-001`
- Service UUID：`7b9f0001-6f3a-4f8a-9f4d-111111111111`
- Status UUID：`7b9f0002-6f3a-4f8a-9f4d-222222222222`
- WiFi Config UUID：`7b9f0003-6f3a-4f8a-9f4d-333333333333`

#### 10.2 行为变化

- 不再构造或 notify GPS/health telemetry。

- 支持通过 USB serial 使用同样配置命令。
- 收到配置后保存到 Preferences，并尝试连接 Wi-Fi。
- 每 2 秒 notify 当前 provisioning status。

  "ssid": "MyHotspot",
  "password": "hotspot-password",
  "host": "192.168.31.199",
  "url": "http://192.168.31.199:3000/api/device/telemetry",

### 4. Architecture Updates

#### 4.1 New Hardware Data Path

```text
GPS v1.1 + Heart Rate HAT + IMU
  -> M5StickC Plus Wi-Fi station
  -> same hotspot / LAN
  -> HTTP POST /api/device/telemetry
  -> Express backend
  -> Prisma + PostgreSQL
  -> latest cache + history query
  -> Main App / Map / Health / Pet Cards / Glass Dashboard / Monitor Dashboard
```

#### 4.2 New BLE Responsibility

```text
Main App Health -> BLE WiFi Setup
  -> Web Bluetooth connects PawTrace-001
  -> write wifi_config JSON to BLE config characteristic
  -> M5 saves SSID/password/upload URL/token
  -> M5 connects to Wi-Fi
  -> telemetry leaves the device through Wi-Fi only
```

#### 4.3 M5 Same-Network LAN API

After the M5 joins the hotspot or LAN, the Wi-Fi firmware serves `http://<m5-ip>:8080`:

- `GET /`: returns device capability and endpoint metadata.
- `GET /status`: returns current live telemetry JSON.
- `GET /telemetry`: alias of `/status`.
- `POST /message`: writes a message to the M5 screen/status state.
- `POST /upload`: queues one telemetry sample and immediately tries to upload it.
- All LAN API responses include CORS headers for same-network phone/laptop demos.

### 17. Known Constraints

- Cloudflare Pages cannot run the current Express/Prisma/PostgreSQL backend directly.
- `release/` is local Electron build output and is ignored because it is large; installers should be distributed through Releases, LFS, or an external artifact channel rather than committed directly to the source repository.
- M5 Wi-Fi firmware still needs final hardware-library integration for production GPS and Heart Rate HAT readings where demo placeholders remain.
- `DEVICE_INGEST_ALLOW_LAN=true` is for same-hotspot or controlled LAN demos only.
- Web Bluetooth requires Chrome/Edge and localhost or HTTPS.
- NFC standalone links that reference a local pet id depend on browser localStorage; cross-device sharing should use encoded NFC payloads.
