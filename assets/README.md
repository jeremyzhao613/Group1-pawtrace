# Assets

Shared static media used by PawTrace pages and packages.

## Important Paths

- `avatars/`: pet or user avatar images.
- `stickers/`: chat and UI sticker assets.
- `source/pet-pictures/`: original pet photo source images.
- `source/head-portraits/`: original portrait source images.
- `1.png` through `6.png`, `m1.jpg`, `m2.png`: general app imagery.

Keep source assets here. Generated build copies belong in `frontend/dist/assets/`
or packaged output folders.
