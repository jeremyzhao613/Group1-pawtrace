# Monitor

Static monitor UI served by the backend at `/monitor/index.html`.

## Important Paths

- `index.html`: monitor page.
- `input.css`: Tailwind input for the monitor page.
- `assets/monitor.css`: generated CSS output.
- `tailwind.config.cjs`: monitor Tailwind config.

Build the monitor CSS and copy it into the frontend distribution with:

```bash
npm run build:monitor
```
