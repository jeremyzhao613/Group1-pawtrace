# Plans

Project planning notes, release records, and supporting screenshots.

## Layout

- This folder root: canonical version plans, release notes, and startup guides.
- `archive/`: duplicate or legacy planning files kept for reference.
- `images/`: screenshots and visual evidence used by plan documents.

Use this folder for release-note Markdown files instead of placing them at the
repository root.

## Current Naming

- `pawtrace-4.0.1.plan.md` through `pawtrace-8.0.0.plan.md`: older plan-style records.
- `pawtrace-8.x.x.md`, `pawtrace-9.0.0.md`, `pawtrace-10.x.x.md`: release notes and implementation records.
- `pawtrace-windows-macos-startup-guide.md`: desktop startup guide.

Keep future version Markdown files here using `pawtrace-<version>.md`.
